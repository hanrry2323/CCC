# mx (medio-0) 历史教训

> 来源：`docs/projects/mx/README.md` 附 C、`lessons.md`、mx025 审计
> 维护：每次机审打回或生产事故后更新

## 1. 网络存储误删保护（2026-07）
- **根因**：增量扫描使用 `Path::exists()` 判断文件存在，网络挂载暂时断开时返回 false → 误删
- **修复**：增量扫描不进行删除操作；全量扫描设置 10% 最小阈值守卫
- **适用场景**：任何涉及文件系统扫描的改动

## 2. iOS Safari 播放权限（2026-07）
- **根因**：切换视频时重建 `<video>` 元素导致 iOS Safari 丢失播放授权
- **修复**：切换时复用同一 `<video>` 元素，播放触发保持在手势上下文内
- **适用场景**：前端视频播放器改动

## 3. 播放列表 refill 状态丢失（2026-07）
- **根因**：refill 自动加载下一批时未保存 `randomContext` → 串文件夹
- **修复**：设置播放列表时同步写入 random context
- **适用场景**：播放列表/分页加载逻辑改动

## 4. WebSub 断链（2026-08 · mx025 审计）
- **根因**：路径重构后 `src/backend/core/src/rss/service.rs:94` 附近 WebSub 联动被注释禁用
- **状态**：mx026 修复中（P0）
- **适用场景**：RSS 模块路径或依赖变更

## 5. RSS 事务边界（mx025 审计）
- **风险**：订阅更新与保存不在同一事务 → 部分失败时数据不一致
- **适用场景**：RSS 数据写入逻辑改动
