# clw (clwarp) 审查维度

> 审查重点：PTY 生命周期、IPC 边界、红线合规、前端错误处理

## 审查重点

1. PTY 生命周期：spawn 后子进程是否正确启动（默认 shell）；关闭/销毁时是否回收（无僵尸进程）
2. 边界与异常：session 不存在返回 Err 不 panic；非阻塞读不忙转死锁；EOF 后前端停止轮询
3. 红线合规：不触碰 `~/.claude/`、`~/.codex/` 等用户配置；不写业务项目文件；数据目录 `~/.clwarp/`
4. 范围合规：改动限卡内白名单文件，无无关文件混入
5. IPC 安全：Tauri command 参数校验，不泄露宿主敏感路径

## 可修范围（就地修，不打回）

- 命名 / 注释 / 小重构 / 补充测试

## 不可修（打回）

- 触碰用户 CLI 配置 / 写项目文件 / 系统性越界 / 核心业务意图违背
