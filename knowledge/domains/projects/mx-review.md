# mx (medio-0) 代码审查清单

> 项目：medio-0
> 审查重点：基于历史审计发现（mx025）和架构决策（ADR-001~013）

## 审查维度

### 1. RSS 与 WebSub（P0 重点）
- WebSub 联动路径引用是否正确（mx025 确认：曾因路径重构致编译错误后被注释）
- RSS 爬虫事务边界：订阅更新与保存是否在同一事务内
- 增量扫描是否受网络挂载抖动影响（历史教训：`Path::exists()` 误删）
- `test_rss.py` 是否覆盖变更路径

### 2. 数据库与模型
- sqlx 查询是否使用参数化（禁止字符串拼接 SQL）
- Schema 变更是否同步迁移脚本
- 事务是否正确处理错误回滚

### 3. API 层
- axum handler 的 State 提取器签名是否正确（axum 0.8 语法）
- 错误响应是否统一格式
- 认证/授权中间件是否正确应用

### 4. 前端
- React 组件是否正确处理加载/错误/空状态
- 视频播放器 `<video>` 元素是否复用（iOS Safari 权限教训）
- 播放列表 refill 是否保存 randomContext（历史教训：串文件夹）

### 5. 通用
- 禁止引入新 crate 依赖（除非卡内明确允许）
- 不修改 API 契约（除非卡内明确允许）
- 文件路径不硬编码（使用 config.toml 或环境变量）

## 可修范围（就地修复后直接通过）
- 命名规范、注释补充
- 小范围重构（提取函数、简化条件）
- 补充测试用例
- 错误消息改进

## 不可修边界（必须打回）
- 业务逻辑变更
- API 签名修改
- 数据库 schema 变更
- 引入新依赖
