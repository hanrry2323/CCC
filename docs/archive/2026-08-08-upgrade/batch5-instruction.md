## 三、任务（严格按序执行）

### 任务 1：修 P3 —— 空提交信号判成功（核心）

在 main.py 执行收尾判定处（nonzero 分支之前）新增空提交识别：

- **判定**：`returncode != 0` 且日志（`{work.id}.log` 末段）含空提交信号关键词：
  - `nothing to commit` / `no changes added to commit` / `nothing added to commit` / `no commit created`
- **动作**：判成功（`_emit(True, ...)` + return True），problems 可附注「空提交完结（无改动可交）」——**不进重试、不打回、不触发机械门禁**
- **安全边界**：只认日志中确凿的空提交语句（不认 `error:` 行、不认其他非零码如 127/130/137）；匹配须在最后退出阶段（执行体输出尾部）
- 方向：判成功在 nonzero 分支前拦截；**exit 0 机械门禁逻辑一字不改**

### 任务 2：空回写卡检测（收单侧）

- 收单「已回写」前检查卡文件回写区：回写区为空（无分支/commit/凭证内容）→ **打回**，problems 标注「空回写卡（回写区无凭证内容），禁止空提交收单」
- 实现位置：收单校验处（机械门禁附近或回写处理处）；worktree 派发与默认目录派发都生效

### 任务 3：回写凭证字段结构化（收单侧校验）

- 定义回写区最小凭证字段（约定，写进校验器注释）：

- 收单时校验：回写区缺上述任一凭证字段 → 打回（problems 标注缺哪个字段）
- 与任务 2 合并实现为一个「回写凭证校验」函数，供两条收单路径调用
