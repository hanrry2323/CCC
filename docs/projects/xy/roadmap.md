## 双线路执行规则（2026-09-08）

### 开发线（Build）
- 输入：需求、线路图、已发现生产缺口。
- 输出：业务代码、测试、版本提交、可运行版本与验收证据。
- 责任：修复 Worker/编排/正文生成/配图/渲染/质量门禁等软件能力；不得把真实产物当作代码验收替代。
- 卡型：开发、修复、重构、依赖与版本卡；必须绑定 commit 和版本。

### 生产线（Produce）
- 输入：开发线已验收版本 + 选题/内容 brief。
- 输出：文章、图片、脚本、配音、视频及质量报告；默认只落本地，不发布。
- 责任：运行已验证能力、记录产物与质量、归档生产批次；发现代码缺口转开发线，不在生产卡内改代码。
- 卡型：生产批次、内容首跑、质量抽检卡；必须绑定版本号和产物路径。

### 两线闸门
1. 开发版本未通过测试与至少一条真实样片，不得进入生产线。
2. 生产线只允许消费已验收 commit/tag，不允许直接跟踪开发工作树。
3. 生产失败分为内容数据问题、环境问题、软件问题；只有软件问题回开发线。
4. M7 发布线继续冻结，生产线当前只做本地产出与质量验收。
