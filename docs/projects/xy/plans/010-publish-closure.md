## 目标

生产→发布闭环：D4 真发布（当前仅 SAU 桥接，未真发），内容排期/发布计划自动执行，发布效果数据回传展示台（衔接 M6）。M7 之前全部为优化，M7 是产品化的临门一脚。

## 背景

平台通道已就绪：快手/微信视频号发布通道（xy006）、B站/头条 Cookie 扫码抓取工具（xy007）、SAU 桥接（5409）、admin publish_schedules 表基础。缺：真实发布验证、Cookie 生命周期自动化（抓取/续期/失效检测）、排期调度器、效果数据回传。发布闭环完成前，产出只进本地目录（M6 展示台可见），不对外分发。

## 方案内容

四块：

1. **Cookie 生命周期自动化**：B站/头条（xy007 基础）+ 快手/视频号（xy006 通道）Cookie 抓取/续期/失效检测与告警，入库 `cookies` 表（已有）。
2. **D4 真发布通道**：各平台真实发布验证（走通 ≥2 平台），发布状态回写（成功/失败/平台错误码）。
3. **内容排期/发布计划**：publish_schedules 表 + 调度器：按计划自动取产出→发布，失败重试/告警。
4. **发布效果追踪**：平台数据回传（播放/点赞/评论）→ 展示台看板（衔接 M6 数据位）。

## 验收标准

- [ ] ≥2 平台真实发布成功（非桥接占位）

## 功能卡

### Cookie 生命周期自动化

目标：Cookie 抓取/续期/失效检测。

实现：扩展 xy007 扫码抓取工具：失效检测（周期校验）、续期提醒、告警；快手/视频号 Cookie 接入；`cookies` 表状态字段完善。

验收：任两平台 Cookie 入库可校验状态，失效可检测并告警。

颗粒度：抓取/检测/告警，多模块。

依赖：平台 Cookie 就绪（前置）

架构位置：admin/api + 抓取工具（xy007 基础）

### 真发布通道

目标：≥2 平台真实发布走通。

实现：发布桥接（SAU 5409 + 平台通道）真实调用验证：上传产出→发布→状态回写；错误码映射。

验收：≥2 平台发布成功记录入库，发布状态可查。

颗粒度：发布调用 + 状态回写，多模块。

依赖：Cookie 生命周期自动化

架构位置：bridge/sau_bridge.py + 平台适配层

### 内容排期/发布计划

目标：排期调度器自动发布。

实现：publish_schedules 表 + launchd 调度：按排期取最新产出自动发布，失败重试（≤3 次）+ 告警。

验收：排期任务按计划自动执行，发布结果入库。

颗粒度：调度器 + 排期 UI 扩展，多文件。

依赖：真发布通道

架构位置：admin/api + 调度守护

### 发布效果追踪

目标：效果数据回传展示台。

实现：平台效果数据拉取（播放/点赞/评论/完播），入库 + M6 展示台数据位填充。

验收：效果数据在展示台可见，每日刷新。

颗粒度：数据拉取 + 看板填充，多文件。

依赖：真发布通道 + M6 展示台

架构位置：admin/api + 展示台
