## 升级清单 v2

### 一、计划页（50 → 82）

- 卡片尺寸统一：grid 行高固定（内容截断），所有卡等高同宽，不再因内容忽高忽矮
- 标签语义化：去掉「卡 ID + 状态」标签，改为业务标签——计划（方案本体）、缺口（验收未满/无验收项）、警示（关联卡漂移/未关闭/缺失）；标签来源由后端聚合真实风险状态
- 顶部项目切换零漂移：固定列数与容器高度、切换保滚动位置、禁用重排动画；切换后仅更新数据不重建整页布局
- 保留并强化：默认 3 活跃列、终态列按钮切换、列折叠、拖拽改状态（非法流转提示）

### 二、运维页职责重构（50 → 82）

页面改为「项目工程化运维」，数据按项目聚合：
- ① 项目健康卡：每项目一张卡——卡数 / 漂移 / 缺口 / 螺旋循环状态，一眼看哪些项目要维护
- ② 工程化待办（主区）：diff 审查队列（待合入卡 / 打回卡）+ 代码健康发现（Loop 巡查：状态漂移/关联断裂/维护区缺失），按项目分组
- ③ 螺旋循环状态：发现 → 转卡 → 执行 → 机审 → 合入 的循环进度
- 系统健康（节点/服务/管道）从运维页剥离，移交控制台（控制台本轮不动，职责方向记录：系统健康、设置、hp 节点健康、活跃端口、内网网址、中转站管理）

### 三、线路图二级页右侧面板（80 → 85）

- 右侧卡面板按状态分组（已完成 / 进行中 / 待开发 / 风险置顶），每组可收缩/展开
- 卡片带业务进度与时间信息；标签有分类归属，不再平铺一堆
- 左侧垂直里程碑时间线保留不动

### 四、线路图一级页（70 → 82）

- 项目卡对齐二级页总览风格：名称 + 总/完成/进行中/风险统计 + 完成率 + 风险红标
- 顶部筛选：全部 / 进行中 / 已完成 / 有风险；hover 浮起 + 最近活跃

### 五、看板页（55 → 82）

- 列折叠与默认态：默认显示 5 个活跃列（待分派/执行中/机审/已回写/打回），已关闭默认折叠；列头可点折叠 + 计数徽标
- 列宽自适应：折叠后活跃列自动加宽（不再 278px 硬挤）
- 卡片信息层级统一：卡号 + 意图（2 行截断）+ 状态徽标 + 执行体 + 验收/漂移标记 + 打开详情
- 卡片密度切换：舒适/紧凑两档
- 工具栏补搜索 + 计数总览；空列显示引导文案
