## 目标

实现执行 Agent 心智注入，将关联方案的摘要与项目线路近况注入到执行提示中，让 2017 执行 Agent 有上下文地执行任务。

## 背景

执行 Agent 在派发执行时处于上下文真空状态，容易偏离方案设计。

## 方案内容

### 1.1 心智注入

扩展 prompt_inject.py，自动读取卡头关联的方案编号并提取目标和验收标准。

## 验收标准

- [ ] 方案摘要和近况可成功拼入提示。
- [ ] 支持无方案编号优雅降级。
