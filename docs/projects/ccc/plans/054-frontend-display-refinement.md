- 字号阶梯：xs 11 / sm 13 / base 14.5 / lg 18 / xl 28；**卡号/时间/路径/数字一律 `--ccc-font-mono`**。

### 1.2 状态色单一映射表（全站唯一，k-status-badge 单表消费）

| 状态 | 徽标 | 语义 |
|---|---|---|
| 待分派 | muted 灰 | 排队中 |
| 执行中 | info 蓝+呼吸点 | 进行时 |
| 机审 | warn 琥珀 | 待裁决 |
| 已回写 | accent 橙 | 待合入 |
| 已关闭 | success 绿 | 完成 |
| 打回/作废 | danger 红 | 异常 |

计划六态映射进同一张表：已确定=info / 待排期=muted / 部分执行=accent / 待验收=warn / 已完成=success / 作废=danger。落地即删三套各自为政色板（049 对照#8：ui.js STATE_TONES / taskCard / plansPage）。

## 2. 卡片解剖（两类一等公民，字段级规格）

### 2.1 k-task-card（看板卡原子）

```
┌────────────────────────────────────┐
│ tst999  [tst] [机审·warn]           │ 行1：卡号(mono)+项目徽标+状态徽标
│ Web P0 鉴权回归测试卡                │ 行2：标题，1 行截断（title 属性全显）
│ 执行体 ZCode · 3 分钟前 · engine     │ 行3：执行体+agoText+派发源，xs 灰
│ [重新分派] [作废]                    │ 行4：动作按钮（按状态显隐，ghost 款）
└────────────────────────────────────┘
```

- 动作显隐规则（与后端状态机一致，禁自创）：待分派=[无]；执行中=[无]（日志内嵌）；机审=[机审重跑]；已回写=[机审][合入引导]；打回=[重新分派][作废]；任意态=[作废]。
- 卡高 ≤96px；列内间距 space-sm；hover 抬升 shadow-md→lg；拖拽态=accent 边框+半透明。
- 降级态：`/tasks/running` 拉不到运行时指标时，耗时/调用数显示「—」，**不隐藏行**（防布局跳动）。

### 2.2 k-session-card（墙格原子）

```
┌────────────────────────────────────┐
│ ● 会话标题（单行截断）        12 分钟 │ 头：呼吸状态点+标题+时长
│ 最近消息第二行截断……（mono xs）      │ 体：最近消息 2 行截断
│ 47 条 · 2 分钟前 · [输入框────────]  │ 脚：条数+ago+格内发消息入口
└────────────────────────────────────┘
```

- 状态点语义沿用墙呼吸灯：活跃=绿呼吸 / 停滞>15 分钟=warn 静态 / 出错=danger / 完成=灰。
- 未读态：左缘 3px accent 竖条+标题加粗；完成/出错会话转未读区（现有行为保留）。
- 网格：xl1280 四列 / lg1024 三列 / md768 两列 / sm640 单列；格高统一 148px，超出格内滚动。

## 3. 组件视觉规格（049 §3.3 组件族的视觉补充，逐个钉死）

| 组件 | 规格 | 禁例 |

| k-status-badge | 高 20px、radius-full、字 xs，色=§1.2 单表 | 禁页内自定义色板 |

| k-degraded | 全宽横幅：icon+文案+快照时间戳+重试钮，bg=warn-soft | **禁静默陈旧数据冒充实景**（防幻觉纪律的前端化） |
