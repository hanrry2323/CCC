## 项目本质

可脱离 CCC 独立运行的**医药决策调度平台**：三层架构（Workflow 智能规划 / Scheduler 规则调度 / Worker 物理执行），SQLite 持久化账本，低配设备单进程运行（目标 ≤30MB 内存）。爬虫是可插拔执行器，不是产品本体。

## 数据流（全景）

```
采集层（gov 挂网 / 电商 B2B / 社媒舆情）
  → Scheduler 调度（四维标签 + 乐观锁 + 并发槽位）
  → SQLite 账本（jobs / gov_prices / ecommerce_prices / sales_opportunities）
  → Workflow 决策（LLM 双轨：本地 Ollama ↔ 在线 API）
  → 三级合规审核（AI 初审 → 代表复审 → 总管终审）
  → 企业微信秒级推送
  → 前端 SPA 控制台（Vite+React+SSE，FastAPI 一体化挂载）
```

## 草案池

- 社媒舆情探针（media.py：小红书/招标新闻）——M3 之后评估，先不排期
