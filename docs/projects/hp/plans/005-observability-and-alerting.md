2026-08-15 发现 HP PG 僵尸 20h 无人发现（端口通、连接全挂）。修复已做，后端埋点 `/ops/pg-health` 已合入（`1bbabfe5`），但前端渲染与告警推送未接。HP 是集群知识库底座，多处调用，可观测性是稳定性的第一道防线。

## 方案内容

分 5 个子节点执行：

**3.1 健康三态探针**：对 postgres / ollama / memory-store / mcp-server / graph server 五个服务做三态探活（进程 / 端口 / 真实请求），产出统一健康状态。

**3.2 pg-health 前端渲染**：`/ops/pg-health` 后端已就绪（1bbabfe5），前端 consolePage.js 渲染 renderPg（**核查确认：后端已合入，前端无 commit，待办**）。

**3.3 告警推送通道**：PG 僵尸/服务宕机/健康降级 → 主动推送（日志 + 通知通道），异常状态持续标记。

**3.4 悬空 cron 清理**：HP 节点遗留 cron / launchd 任务排查，清理失效项。

**3.5 health 报告自动化**：daily 健康报告 + 异常标记，异常自动拉起/标记，避免静默失效。
