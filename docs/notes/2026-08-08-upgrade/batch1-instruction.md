## 三、任务（严格按序执行）

### 任务 1：修 P6 —— 机审结构化结论判定（核心）

文件：`server/board/models.py` 的 `machine_audit_passed_text()`

要求：
1. **只认结论行**：机审区节内，按行扫描寻找「结论」标记行（形如 `机审：通过` / `结论：通过` / `机审：不通过` / `结论：不通过`，允许 `**加粗**` 包裹），**忽略**表格行（以 `|` 开头的行）、小节标题（`###` 开头）、纯描述文本。
2. **多轮追加语义**：同一 `## 机审区` 节内可能追加多轮（历史不通过轮 + 通过轮）。判定规则 = 该节内**最后出现**的结论行说了算。
3. **噪声排除**：`✅` 字符、`通过项`、`已闭环`、`✅ 满足` 等一律不算结论；「不通过」结论行若含「通过」子串（如「机审：不通过（非0退出）…已较前两轮实质修复…」），必须以**「不通过」优先**解析。
4. 保持函数签名 `machine_audit_passed_text(text: str) -> bool` 不变（调用方：approve-merge.sh、engine/main.py、server/web 均用它）。
5. 保留「逐节检查」的多轮/跨节语义：若卡正文有多个 `## 机审区` 节（异常情况），任一节最后结论为通过 → True。
