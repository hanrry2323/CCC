# 文档收敛治理规范（Convergence Governance）

> **定位**：CCC/qx-map/hp-kb 文档收敛的宪法。定义「删 vs 归档 vs 现行」判定标准、可信度分层、RETRACTED 强制标记、新文档落地规则。
> **目的**：防止文档散落形成新负债；让向量搜索只命中可信文档，历史垃圾搜不出来。
> **依据**：2026-08-11 深度盘点（CCC docs 64 篇 57% 历史 / product 38 篇 28 历史 / qx-map decisions 80 档 / hp-kb 350 条 + schemes 260 污染）。
> **状态**：v1 定稿 · 更新：2026-08-11

---

## 一、核心判据：会不会误导向量搜索

**文档收敛的第一判据不是"有没有用"，而是"会不会被向量搜索搜出来误导 Agent"。**

- 归档不删可以——但归档文档**没有 RETRACTED 标记 = 等于没收敛**，向量搜索照样命中。
- hp-kb 双刃剑：高效检索与历史垃圾被搜出并存。**防护 = 历史文档强制进 T4/T5（带标记或删除），向量索引搜不到。**

---

## 二、删 vs 归档 vs 现行（判定标准）

| 判定 | 标准 | 处置 |
|------|------|------|
| **删** | 明显过期 + 无追溯价值 + 会干扰（项目完结验收记录 / 迁移 stub / 已闭环运维修复 / 死链全文版 / 重复对冗余版） | 移 `__archive__/trash/` 观察 30 天 → 清。**删除前必须确认无现行引用** |
| **归档** | 历史决策有追溯价值（架构定稿 / 事故复盘 / 席位变更 / 退役机制） | 移 `archive/` + **强制标 `RETRACTED`** 头（向量搜索屏蔽） |
| **现行** | 仍指导当前工作（白名单：文件名含方案/定稿/ARC/SOP + 被 INDEX/canon 引用） | 保留 + 提升可信度 T1 |

**红线**：
1. 归档/历史文档**必须带 RETRACTED 标记**——不带 = 没收敛
2. 删除前必须 grep 确认无现行文档引用（防断链）
3. 重大决策/架构定稿永不删（永久基线不衰减），只归档标记

---

## 三、可信度分层（T1-T5）

> 融合 Temporal Knowledge Tiering（1周1.0 / 1月0.7 / 超1月0.3；白名单不衰减；RETRACTED 屏蔽）。

| 层 | 定义 | 检索行为 | 文档类型 |
|----|------|----------|---------|
| **T1** | 权威现行（白名单 + 不衰减） | 全文返回，优先展示 | ENGINEERING-CANON / onboarding / DOC-PROTOCOL / registry / INDEX §0 / 红线类 / ADR / current-state-v070 |
| **T2** | 1 周内活跃 | 权重 1.0 | 每日流水 / 近期卡 / 近期 lesson |
| **T3** | 1 月内 | 权重 0.7，摘要态 | 中期方案 / 教训 |
| **T4** | 历史归档 | **检索屏蔽**（只留"单一历史索引"指针，正文禁全文） | 归档决策 / 完结项目 / 退役机制 |
| **T5** | RETRACTED / 垃圾 | **不返回** | 冲突硬规则 / 死链 / 污染快照 / 重复冗余 |

**T4/T5 的向量防护**：
- T4 文档在 hp-kb 只放"标题 + 摘要 + 指针"（符合"hp-kb 只做检索索引"红线），正文禁存
- T5 一律删除或标 `RETRACTED` 前缀
- `/codex/schemes/` 整段快照 = 污染源，整域降权或清

## 四、单一历史索引机制

- **HUB-ERA-DEPRECATED-INDEX** 是范本（已列全部废弃条目 + 典型过期关键词），扩展为通用历史索引。
- 历史文档收敛方向：**不逐条留**，合并进"单一历史索引"条目，正文禁全文。
- 归档决策索引：指向 qx-map `__archive__/decisions/` 原文（永久基线），hp-kb 只留指针。

---

## 五、新文档落地规则（防再散落）

1. **写规范前先查**：INDEX.md / ENGINEERING-CANON 是否已有同主题；有则更新不新建。
2. **新规范落点**：流程细则进 CCC `docs/`；决策定稿进 qx-map `__archive__/decisions/`；检索索引进 hp-kb（标题+摘要+指针）。
3. **禁止双写**：同一 SOP 只允许一个权威源，另一侧留指针（grep 查重复）。
4. **退役必标记**：任何文档被取代/作废，立即标 RETRACTED + 更新引用，不留"无标记的史"。

---

## 六、执行流程（收敛动作模板）

```
① 盘点（子 Agent 扫描 → 分类清单）
② 引用审计（grep 确认删除对象无现行引用）
③ 执行（删 → trash/ 或 归档 → archive/ + RETRACTED）
④ 断链修复（更新指向被归档/删除文档的引用）
⑤ 验收（数量对账 + hp-kb 检索抽查：历史搜不出 + 现行可命中）
```
