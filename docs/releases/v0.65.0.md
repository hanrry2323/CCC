# CCC v0.65.0 — 正式上线（意图链 + 编排自愈）

> 日期：2026-07-30 · VERSION SSOT：`VERSION`

## 一句话

人在 Desktop 聊定意图 → Agent **自动投意图链** → Engine 跑 → 失败 **自动修板并优化再投**；快捷钮仅「对齐基线 / 扫风险」。

## 上线能力

| 能力 | 口径 |
|------|------|
| **意图链开发** | Agent 收敛后自动出多卡 `ccc-transfer`；gate 绿进代办 + wake；**无**「转意图卡」按钮 |
| **平台任务自愈** | abnormal/板堵 → `hub_repair`；可恢复 reopen；耗尽 → `optimize_hint` 优化意图链并**自动投**；清障 ≠ 结案 |
| **快捷钮** | 仅「对齐基线」「扫风险」 |
| **红线** | invent 硬关；不对 orch 写业务 epic；不把老板当维修工 |

## 主路径

```text
聊透意图 → Agent 自动投链 → gate → backlog → Engine
  → 绿：released / probed → 飞轮下一站
  → 红：repair + 优化链再投（禁只 ui_hidden）
```
