## 席位

| 席位 | 绑定 | 做什么 |

| **执行会话** | 默认开发（自动化值班组件执行） | 写码 → 已回写；机审由验收席独立审查 |

| **桌面端管理席** | 出卡/裁决 | 出卡/裁决 |
| ~~Cursor~~（已弃用 2026-08-14） | 难度突击由执行会话顶替 | — |
| **桌面端/主 IDE** | 合入执行体 | 取证 → 人话 diff 摘要 → 等「合入批准」→ approve-merge；不做二次审查 |

## 主路径

```text
| 席位 | 绑定 | 做什么 |
|------|------|--------|
| **前段执行** | **DSH**（可替换插件） | 开发 + 前置机审 → 已回写 |
| **后段执行** | **CC CLI（phase2）**（可替换插件） | 审核/验收/合入/部署 → 已关闭 |
| **管理席** | 可替换调度插件（现役外脑） | 拟指令、调度、监督 |
| **老板** | 否决/打回权 | 重大合入可要求人审 |
| **HTTP 看板/运维** | 实时面 | 查看状态与健康 |
```

质量过不过看机审/门禁 exit code，不看口头流程。「验收看板」及旧同义句 = **合入批准** 别名。

前段与后段职责按注册表绑定，工具均可替换；老板保留否决/打回权，重大合入可要求人审。

## 红线

1. 开发禁止写机审区/验收区/已关闭。  
2. 机审禁止改业务码、禁止已关闭。  
3. 合入前取证认 `origin/codex/<stem>`（`card-evidence.sh`）；进度认 2017 API。  
4. 禁止新增验收同义句/席位 SOP（INDEX §0 反目标）。
