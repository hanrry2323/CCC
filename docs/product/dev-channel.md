# 开发通道 — 谁改 CCC（2026-08-07 北星）

> **老板面**：主调度插件拟指令 → 盯看板；中间自动。
> **前段**：DSH 开发+前置机审，完成后回写。
> **后段**：CC CLI（phase2）负责审核/验收/合入/部署；合入默认自动，老板保留否决/打回与重大合入人审。
> 竖切：[`north-star-slice.md`](north-star-slice.md)

## 席位

| 席位 | 绑定 | 做什么 |
|------|------|--------|
| **前段执行** | **DSH**（可替换插件） | 开发 + 前置机审 → 已回写 |
| **后段执行** | **CC CLI（phase2）**（可替换插件） | 审核/验收/合入/部署 → 已关闭 |
| **管理席** | 可替换调度插件（现役外脑） | 拟指令、调度、监督 |
| **老板** | 否决/打回权 | 重大合入可要求人审 |
| **HTTP 看板/运维** | 实时面 | 查看状态与健康 |

## 主路径

```text
主调度插件拟指令 → 前段 DSH 开发+前置机审 → 已回写
  → 后段 CC CLI（phase2）审核/验收/合入/部署 → 已关闭
```

质量过不过看机审/门禁 exit code，不看口头流程。「验收看板」及旧同义句 = **合入批准** 别名。

前段与后段职责按注册表绑定，工具均可替换；老板保留否决/打回权，重大合入可要求人审。

## 红线

1. 开发禁止写机审区/验收区/已关闭。
2. 机审禁止改业务码、禁止已关闭。
3. 合入前取证认 `origin/codex/<stem>`（`card-evidence.sh`）；进度认 2017 API。
4. 禁止新增验收同义句/席位 SOP（INDEX §0 反目标）。
