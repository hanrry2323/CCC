## 步骤

1. **取证**（CodeRun 编排）：并行读双仓 git 状态（历史/分支/无共同祖先确认/各自源码差异清单），输出合并方案前置证据。
2. **备份回滚点**：双仓 git bundle 快照，落盘。
3. **设计合并方案**：确定合并策略（以 SSOT 为准，hp 部署仓历史并入/重建），输出方案。
4. **执行合并**：按方案归一为单一线性历史，SSOT=mac2017。
5. **验证**（编排并行）：双仓历史一致、SSOT 为真值、hp 部署仓可派生、无内容丢失。
6. **记录**：合并命令输出、前后状态对比、快照路径，全落档。
7. commit+push 到卡内分支（勿直推 main）；合入前 `git fetch origin && git rebase origin/main`（减 --close-only）；卡头改为「已回写」。
8. **停手**：禁止写 `## 机审区` / `## 验收区` / 置「已关闭」。等 2017 机审 → 老板「合入批准」。
