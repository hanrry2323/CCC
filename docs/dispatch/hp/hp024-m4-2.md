## 实现

**CodeRun 编排要求（重点）**：
- 用一段编排程序（内存脚本/内联程序，cc-run-inline 式）完成多步骤：**并行取证 → 分批重灌 → 并行验证**，而不是逐轮串行工具调用。
- 重灌数据源：hp-kb `kb_status` 确认过期项目（已探针：15 个过期，2 大项目 claude-code/engineering 23217 chunks、ai-instruction/research 21433 chunks）。
- 重灌通道：HP ingest 链路（`/data/ingest`，PG18 `/data/pg-knowledge`）。HP 访问走 `ssh hp`（config，非 id_ed25519_hp 直连）。

**回滚保障（硬）**：重灌前必须对每个目标项目备份「原 last_ingest + 原 counts」，落盘为可回滚快照；重灌异常可恢复。

## 步骤

1. **取证**（CodeRun 编排）：并行读 kb_status 过期清单 + HP ingest 通道状态，输出重灌目标清单。
2. **备份回滚点**：对目标项目记录原 last_ingest/counts，落盘快照。
3. **分批重灌**：先 2 大项目（claude-code/engineering、ai-instruction/research），验证后继续中小。
4. **验证**（编排并行）：kb_status 复核 last_ingest 已更新 + chunks 数合理（非 0/非异常）。
5. **记录**：重灌命令输出、前后状态对比、快照路径，全落档。
6. commit+push 到卡内分支（勿直推 main）；合入前 `git fetch origin && git rebase origin/main`（减 --close-only）；卡头改为「已回写」。
7. **停手**：禁止写 `## 机审区` / `## 验收区` / 置「已关闭」。等 2017 机审 → 老板「合入批准」。
