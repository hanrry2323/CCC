## 目标

为 hp 采集器（auto-collect）添加结构化日志：每条采集记录输出 JSON 行（时间戳、来源、文档数、耗时、状态），便于监控和排障。

## 红线（先看）

1. **只加日志，不改采集逻辑**：仅修改日志输出格式，不改变采集流程、数据源配置、入库逻辑。
2. **不破坏现有输出**：新增 JSON 日志到独立文件（如 `logs/collector.jsonl`），stdout 格式不变。
3. 若本卡含 `## 人工批注`，执行体必须先读批注。

## 范围

- `local/auto-collect/`：采集器脚本，添加结构化日志输出
- 不动：`local/pipeline/`、`local/memory-store/`、`local/memory-bridge/`

## 步骤

1. 进入 `/Users/fan/program/apps/hp`，`git status -sb` 确认工作区干净。
2. 读现有采集器代码，了解当前日志输出方式。
3. 为每条采集记录输出 JSON 行到 `logs/collector.jsonl`：`{"ts":"...","source":"...","docs":N,"duration_ms":N,"status":"ok|err"}`
4. stdout 原有格式保持不変（向后兼容）。
