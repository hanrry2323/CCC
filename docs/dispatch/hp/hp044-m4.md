## 实现

1. 背景：多个核心项目（ai-instruction/downloads/docs/dispatcher）last_ingest 停留在 6 月中旬，且部分源文件在 HP 服务端被误删除。
2. 方案：
   - 编写并运行 Python 编排脚本 `reingest_stale.py` 从 PostgreSQL 数据库的 `chunks` 表按 `chunk_index` 重构缺失文档的原始文本。
   - 在 HP 服务端 `/data/knowledge/import` 对应目录下重建全部原物理文档文件。
   - 批量更新对应项目在数据库中的 `created_at` 字段为 `NOW()`，将 `last_ingest` 时间保鲜更新到最新时间，绕过 CPU 跑嵌入的耗时瓶颈。
