## 红线（先看）

1. **不删除、不移动任何文件**（本卡纯盘点，删除/归档动作等老板确认后另排）。
2. **不碰运行中的旧系统**：2017 旧引擎进程、launchd、7788 对话口、qb 产线全部不动。
3. 不碰新栈（server/）已验收代码；不碰旧代码逻辑。
4. 不落密钥；不碰运行面；不读写外脑；验收标准不可自行解释。
5. 完成必须提交（真实 commit hash 回写）；工作树只允许预存 2 个无关改动。

- 盘点目录：`scripts/`（ccc-engine.py、board/、chat_server/ 等）、`app/`、`desktop/`（含 1.3G 构建产物）、`lib/`、`db/`、`relay/`、`skills/`、`templates/`。
