## 目标

工作流可视化页（M6 核心）：类扣子节点流展示生产进度——打开页面看到任意生产任务当前走到哪个节点，节点状态实时更新（≤10s 轮询），失败节点可跳日志。

## 实现

①`admin/pages/` 新增工作流页：按 pipeline stage 定义渲染节点流（SVG/轻量实现，不引重型框架），节点状态着色（完成=绿/进行中=蓝/排队=灰/失败=红）。

②数据源只读调用 xy053 已合入的 `GET /api/v1/workflows`；10s 轮询刷新。

③失败节点可点击跳转现有日志页（logs 页路由，以实测为准）。

④空任务/无记录降级展示空态，不报错。

⑤补测试：节点状态映射/着色逻辑可测部分。
